# 独立前端交互图 V1

运行中的 React 页面即**可点击原型**；本文件标注区域、动作与接口，不另维护会与代码脱节的静态页面。

## 桌面布局

```text
┌──────────────────────────────── Mini GPT Researcher ──────────────────────────────┐
│ 新建研究（左栏）                 │ 报告 / 研究计划 / 来源（右侧主区）     下载 MD/HTML │
│ 研究主题 [多行输入]              │ 空状态：说明如何开始                         │
│ 参考资料 [选择 PDF/Markdown]     │ 成功：报告正文、引用编号                     │
│ 文件名、数量、大小与限制         │ 计划：研究问题与轮次                         │
│ [开始混合研究]                   │ 来源：S1…网页链接或文档名、页码、片段      │
│ 当前状态 / 错误                  │ 任务信息：ID、次数、用量                     │
└────────────────────────────────────────────────────────────────────────────────────┘
```

窄屏按“标题 → 输入与文件 → 状态 → 结果”纵向排列。结果标签可以横向滚动，但主内容和操作按钮不能被裁切。

## 控件与行为

| 控件 | 动作 | 约束/反馈 |
| --- | --- | --- |
| 研究主题 | 输入和修改主题 | 只传去除首尾空白后的非空文本 |
| 文件选择 | 选择 1–5 个 `.pdf`/`.md` | 单文件 10 MiB、总计 30 MiB；页面显示文件名与大小 |
| 开始混合研究 | 校验→上传→研究 | 忙碌时禁用；重复点击不重复发请求 |
| 报告/研究计划/来源 | 切换结果视图 | 无报告或失败时不显示假结果 |
| 下载 Markdown/HTML | 下载返回的原文 | HTML 只作为文件下载，不在页面执行 |
| 网页来源链接 | 新标签打开 HTTPS/HTTP URL | 文档来源显示名称、页码、片段，不伪造链接 |

## 接口映射与状态

```text
idle ─校验成功→ uploading
uploading ─POST /knowledge-bases（multipart files）→ knowledge_base_id + ready
ready ─POST /research（topic, retrieval_mode=hybrid, knowledge_base_id）→ researching
researching ─status=completed 且 report 存在→ completed
任一步 HTTP/网络错误、status=failed 或缺报告→ failed（可修改并重试）
```

`POST /research` 是同步接口，`researching` 只表示请求尚未返回。报告引用只做编号核对，用户仍需检查原文是否支持结论。
